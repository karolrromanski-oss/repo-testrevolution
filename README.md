# repo-testrevolution

Prosta aplikacja z fiszkami do nauki anatomii (HTML + CSS + JS, bez zależności).

## Uruchomienie

```bash
python3 -m http.server 8000 --directory fiszki-anatomia
```

Następnie otwórz http://localhost:8000. Plik `fiszki-anatomia/index.html` można też otworzyć bezpośrednio w przeglądarce.

## Struktura

- `fiszki-anatomia/index.html` – cała aplikacja (fiszki, style, logika)
